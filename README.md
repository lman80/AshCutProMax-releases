# AshCut ProMax downloads

[**Download the latest version for Mac**](https://github.com/lman80/AshCutProMax-releases/releases/latest)

| Your Mac | Choose this installer |
| --- | --- |
| Apple Silicon — M1, M2, M3, M4 or newer | The file ending in `arm64.dmg` |
| Intel | The file ending in `x64.dmg` |

Open the DMG and drag **AshCut ProMax** into **Applications**. ZIP downloads are also available.

The app is ad-hoc signed and is not notarized by Apple. If macOS blocks the first launch, try opening it, then go to **System Settings → Privacy & Security → Open Anyway**.

FFmpeg and FFprobe are included. Install [Node.js 22 or newer](https://nodejs.org) for transcription and caption rendering; the app downloads HyperFrames and models when first needed. Word alignment and rice cut-out also need Python 3.11 or [uv](https://docs.astral.sh/uv/), and download their engines on first setup.

## Updates

Click **Check for Updates** in the app's library sidebar, or choose **Help → Check for Updates**. When a newer version is available, **Download update** opens the installer for your Mac.

Quit the app before replacing the old copy in Applications. Your library and projects are retained. Each release includes SHA-256 checksums and third-party notices.

This public repository contains app downloads and installation instructions. The application source is maintained in a separate private repository.
